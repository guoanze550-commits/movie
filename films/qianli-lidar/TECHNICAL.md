# LiDAR 重制技术说明

本片使用官方 LiDAR Survey 渲染语法与现有 Lemo-Opuscar 逐帧/声音/封装管线，新的代码是作品的点云、地形和镜头，不是另一套视频引擎。不修改上游 core 或 styles。

## 数据

原创艺术高度场：非对称山脊、连续曲流河谷、域扭曲多尺度结构；随后依据D8降水汇流计算树枝状沟道并切蚀几何，再采样。不是仅靠提高粒子数掩盖简单锥体。

1模型米三角网格，同时驱动地表点采样和实体。模型点先量化水平坐标，再求同一三角面高度；垂直量化误差与地面网格差另有实测报告。短半径2/5/10模型米、8方向遮蔽烘焙为AO，法线为带符号8位，掠射光约27°。点强度包含相同的坡向照明与AO，随机量只调制稳定强度。

每个80×80模型米页：UInt16×3坐标（1厘米量化）+四个byte（艺术分类、强度、相对地面高度、固定LOD排序）。局部原点避免大坐标精度损失。60页按4页一批加载，在READY前完成本镜头所需数据；运行期不随机请求或改变点位置。

地表数据每点为UInt16×3、Int8×3法线、Uint8 AO。建筑由相同的曲屋顶/台基/柱廊生成函数采样点云及屋顶表面；桥有弧形桥面与独立栏柱；建筑柱脚接入该位置坡面，不是悬浮立方体。

## WebGL

GPU THREE.Points 自定义shader，真实三维坐标、深度测试与深度写入，近裁剪0.7 / 远裁剪1350模型米，highp计算，实际深度位数由运行报告记录。各块设置解码后世界空间包围球以做真实视锥裁剪。按投影视距与稳定rank降低远处点密度，不随时间重新撒点。

点直径0.24模型米，经投影/视距计算，最小1输出像素，最大3.2输出像素；边缘软圆盘。相机进入点云时近点与远点有不同的投影光流，不是移动贴图。2×内部渲染（1080p输出对应3840×2160缓冲）后缩小；无电影颗粒。离线截图启用保留绘制缓冲，并在每帧完成GPU命令后交给官方截图工具。近黑纯色背景，非渐变。

前沿是 `dot(world, (.76,0,.65))-front`，点和实体shader共享同一uniform对象与平面函数。实体只在同址前沿之后填充；亮缝约0.5模型米、点前沿约1.5模型米；高阈值低强度bloom只接收前沿超阈值亮度，其余画面不泛光。

林冠切面按相对地面高度裁切，坐标不抬升、不摇摆。强度/分类只改变显示，不移动数据。地形等高线用fwidth维持细线；模型地标标注经同一个摄像机world→screen投影，不提供虚假测绘结论。

## 镜头、文字、音频

7秒单镜头C1位置/目标曲线；先低角度进入谷口，后随扫描抬升后拉以读出实体与远景关系。无旋转特效、手持噪声或切镜。

“艺术重建 · 非实测”与实际模型点数全程显示，最小20px（1080p），字体自托管、覆盖验证并通过官方readcheck。技术段无旁白/对白，故没有伪造字幕SRT。TREATMENT另列未来45秒四阶段结构。

原创声音分music / foley / ambience三轨，全部事件从timeline.js读取；官方sfx和mux运行，目标-14LUFS / 真峰值≤-1.2dBTP。主观听感需人工审核，不以响度通过代替声音艺术验收。

## 构建与验收

`bash films/qianli-lidar/build.sh` 仅渲染7秒测试；加 `--data` 可先重建二进制数据。GitHub Actions的Render film输入 `project=films/qianli-lidar`、`profile=production`，production仅指测试片使用1080p。

数据SHA、点数/类别、点面重合、任意时刻反序PNG、坐标不变、深度开关、相机连续、扫描单调、真实三维视差和所有解码帧的连续性分别有证据。完整45秒未制作；只在用户审核视觉质量后启动。
