# 真实性与数据说明

| 声明 | 证据 / 方法 | 限制 |
|---|---|---|
| 艺术重建，非实测 | 用户2026-10-22制作任务；`tools/build-data.py`原创算法与固定种子82177；画面持续标记 | 不代表王希孟画中地形的真实地理位置，不是考古或测绘证据 |
| 点数 | `data/manifest.json` 中各块 n 的和；`tools/verify-data.py`逐块验证 | 数量指艺术模型采样点，不称为激光回波 |
| 60个空间块 | 模型范围x[-240,240)、z[-80,720)，80×80模型单位页 | 模型米是制作尺度，不是历史遗址面积或地理坐标 |
| 坐标量化 | 每轴UInt16×0.01+局部原点；每轴舍入误差上界0.005模型米 | 这是数值存储分辨率，绝非测量精度或真实地面精度 |
| 四种类别 | art_terrain / art_forest / art_architecture / art_water | 自定义艺术标签，不冒充LAS标准分类或提供者分类 |
| 点云与地表同址 | 同一侵蚀高度场、同一1模型米三角网格采样；QA测点到对应三角面差 | 无点位变形，无随机爆炸；建筑曲面网格为同一解析生成器的离散逼近 |
| 无垂直夸大 | 模型数据1:1使用，没有为显示再放大高度 | 艺术模型本身不是真实地形，不讨论真实地形高程 |

文化参考为《千里江山图》的长卷山水与亭桥空间意象。没有使用画作扫描图像、真实地形数据、Google三维瓦片或商业扫描数据。不存在任何“发现古代遗址”“测出山高/桥高”或虚构年代、坐标的结论。

官方风格语法来源：仓库 `upstream/lemo-opuscar/styles/lidar-survey/STYLE.md`，固定上游 b5e8ef93930b6d828f352055a689320f138237b1。官方默认真实场地前提由本次用户明确允许的艺术重建例外替代；其坐标稳定、扫描、分类、深度和审慎标注原则仍保留。
